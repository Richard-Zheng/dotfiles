# Curated i3blocks-contrib scripts

This directory contains only the blocks referenced by `config.tmpl`. The
scripts originate from [i3blocks-contrib](https://github.com/vivien/i3blocks-contrib)
and are distributed under the license in `LICENSE.md`.

The prebuilt `bandwidth2` and `cpu_usage2` executables are accompanied by their
C sources and Makefiles so they can be rebuilt when needed.
